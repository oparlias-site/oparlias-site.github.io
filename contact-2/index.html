About GPG

The block of text on this page is my GPG public key (GPG stands for GNU Privacy Guard, sometimes also called GnuPG). It's a tool for encrypted communication and digital verification.

If you'd like to send me something sensitive — a private message, a password, or anything you'd rather not have travel across the internet in plain text — you can use this key to encrypt it so that only I can read it. Conversely, if you receive a message supposedly from me, you can use my key to check that it was really me who sent it and that it hasn't been tampered with.

How it works, in brief

GPG uses public-key cryptography. Each person has a matched pair of keys: a public key that they share freely (like the one on this page), and a private key that they keep secret. Anything encrypted with the public key can only be decrypted with the corresponding private key, and vice versa. This is what makes both confidential messaging and verified signatures possible.

How to use my key

If you'd like to send me an encrypted message:

  1. Import my key into your GPG software (e.g. gpg --import mykey.asc).

  2. Encrypt your message with it (e.g. gpg --encrypt --armor -r my@email.address message.txt).

  3. Send me the result — I'll be the only one able to read it.

If you use an email client with built-in PGP support (such as Thunderbird with Enigmail, or a plugin like Mailvelope), you can usually just paste my key in and it will handle the rest.

Learn more

GPG is widely used and well documented. A few good places to start:

  • GnuPG official site — gnupg.org — downloads and documentation

  • GnuPG manual — gnupg.org/documentation/manuals/gnupg

  • Wikipedia: Pretty Good Privacy / GNU Privacy Guard — for the history and concepts behind it

  • The GNU Privacy Handbook — a friendly, thorough introduction for beginners

  • Keybase or keys.openpgp.org — services for publishing and looking up public keys

If you're new to this, don't worry — you don't need to understand the math to use it. Any of the guides above will walk you through installing the software and encrypting your first message in a few minutes.
